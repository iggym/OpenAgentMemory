Connect GitHub Repo or Worker

Keep private memories in a Private GitHub Repo (one fine-grained PAT, zero servers) or deploy worker.js to Cloudflare Workers Free tier to route public/* & shared/* to a GitHub Gist and private/* to your private repo.

Quickstart CLI / HTTP Examples (Cloudflare Worker)

Once worker.js is deployed, any coding agent or shell script can read and write memories with plain curl:

# 1. Write a private memory (routes automatically to your Private GitHub Repo)
curl -X POST "https://oam.YOUR-SUBDOMAIN.workers.dev/records" \
  -H "Authorization: Bearer $OAM_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "namespace": "private/preferences",
    "key": "pr-style",
    "title": "Keep pull requests under 300 lines",
    "content": "Split large refactors into stacked, independently testable PRs.",
    "kind": "preference",
    "provenance": { "actor": "user:me", "source": "manual" }
  }'

# 2. Fetch rendered AGENTS.md directly into your project root
curl -H "Authorization: Bearer $OAM_API_TOKEN" \
  "https://oam.YOUR-SUBDOMAIN.workers.dev/export/agents.md" > AGENTS.md

# 3. Query public/* memories (routes to GitHub Gist, readable without auth)
curl "https://oam.YOUR-SUBDOMAIN.workers.dev/records?namespace=public"

Specification Overview — oam.record.v1

Full RFC-style specification lives in SPEC.md. Every OAM record is a self-describing JSON document addressed canonically by oam://<namespace>/<key>.

Field Type Req Semantics
schema"oam.record.v1"YesFormat version discriminator.
idstringYesGlobally unique immutable version ID (e.g. oam_20261122_a9f3c1e2).
namespace, keystringYesSlash-delimited lowercase namespace + key forming oam://<ns>/<key>.
title, contentstringYesConcise summary and plain-text or Markdown memory body.
kind, tags, confidenceenum / array / 0..1Optfact | preference | decision | procedure | context | constraint, tags, certainty.
valid_from, valid_toISO-8601 / nullYesValid Time interval [valid_from, valid_to) when the claim holds in the world.
recorded_atISO-8601 UTCYesSystem Time when this version was asserted (immutable audit clock).
expires_atISO-8601 / nullOptHard retention TTL. Excluded from active recall once elapsed; distinct from valid_to.
version, supersedes, superseded_byint / ID / nullYes*Append-only version chain. Active heads have superseded_by: null.
provenanceobjectYesRequired actor & source; optional method, trust, session_id.
citationsobject[]OptEvidence links: { uri, label?, excerpt?, accessed_at? }.

Fail-Closed Namespace Routing

Routing uses an explicit allowlist for public/shared backends. Any typo or unrecognized namespace defaults to the private GitHub repository so sensitive data never leaks to a Gist.

Namespace PatternBackend TargetStorage Format
public, public/* GitHub Gist oam__public__<sub>--<key>.json
shared, shared/* GitHub Gist oam__shared__<sub>--<key>.json
private, private/*, all others Private GitHub Repo memories/<namespace>/<key>.json + memories/index.json
